# Licence decision required before public release

No source-code licence is assigned by this preparation step because a licence changes the legal permissions granted to downstream users.

Before making the repository public, the authors should select a licence. Common choices are:

- **MIT**: short and permissive; requires preservation of copyright and licence notice.
- **BSD-3-Clause**: permissive and includes a non-endorsement clause.
- **Apache-2.0**: permissive with an explicit patent grant and more detailed terms.

Do not copy a dataset licence onto the code. DREAMER, FACED, SEED, SEED-IV, and SEED-V remain governed by their own access and reuse conditions, and no dataset file should be committed here.
